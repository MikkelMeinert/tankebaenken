# SETUP-PHONE — Tankebænken

## 1. Install the app (iPhone)

1. Open Safari → `https://mikkelmeinert.github.io/tankebaenken/` (after Pages is live).
2. Share button → **Add to Home Screen** → Add. Opens fullscreen, works offline.
3. Same URL on the Mac for the PC side (bench sessions live there). The two installs
   do NOT share data — the phone is for Quarry capture, the PC for bench sessions and
   filing cards. Back up from whichever device you log on (Settings → Export backup);
   if you ever log on both, keep the PC as the master and import backups there.

## 2. Create the Sparring Partner Project (claude.ai)

1. In the Claude app (phone or desktop — Projects sync across both): Projects → New
   project → name it **Sparring Partner**.
2. Paste the full text of `PROJECT-INSTRUCTIONS.md` into the project's instructions.
3. Optionally add `epistemics-training-brief.md` and `CLAUDE.md` as project knowledge.

## 3. The weekly loop

- **Bench (PC, 1×/week):** Tankebænken → Start bench session → Share/copy → paste
  into Sparring Partner → think out loud together → session ends with a STONE CARD v1
  → File stone card in the app. Done.
- **Capture (phone, whenever):** Tankebænken → Quarry → type the idea → Capture.
  Ten seconds. No ceremony.
- **Reading (couch, 2–3×/week):** log thinking-books in two taps. Fiction: never.
- **Return:** after you take a stone back into a conversation — Mark returned, one
  line on what happened.

## 4. Backup habit

Settings → Export backup → save to Files/iCloud. The header shows a "backup due" chip
after 10 unlogged entries. Do it — localStorage is sturdy but not sacred.
